Текст сообщений защищён AES-256. Картинки заливаются на CDN — шифруется только URL ссылки. Прямой доступ к файлу на CDN остаётся открытым по ссылке.
Ключ шифрования (AES-256)

Пароль не передаётся на сервер. Он используется браузером для расшифровки локально.
Статус шифрования медиа
1. Текст и ссылки: Зашифрованы на клиенте через AES-GCM (PBKDF2 SHA-256).
2. Медиафайлы: Отправляются через Go-прокси (`go.justrcat.lol`). В базу Supabase попадает зашифрованный URL, но сам файл доступен на CDN без авторизации, если ссылка будет скомпрометирована.
