CoolDiskRecorder

Сервис загрузки и генерации аудио-команд для систем RCS. Позволяет скачивать треки по прямым ссылкам и создавать локальные команды воспроизведения.

Доступные команды

DOWNLOAD

/cd download

Скачивает аудио по прямой ссылке и сохраняет файл в систему.

/cd download "ссылка" "название песни.mp3"
CREATE

/cd create

Создаёт локальный аудиофайл для дальнейшего воспроизведения.

/cd create "название.mp3"
API

Vercel API System

Можно подключать серверные функции через Vercel для обработки ссылок и конвертации.

POST /api/cd-download

Как это работает

1. Отправка ссылки

Пользователь отправляет ссылку через команду

2. Загрузка файла

API загружает аудио файл

3. Создание записи

CDR создаёт локальную запись и команду воспроизведения

4. Доступность

Файл становится доступен в системе RCS

Загрузить аудиофайл

Перетащите файл сюда или кликните для выбора

Поддерживаются форматы: MP3, WAV, FLAC, OGG
