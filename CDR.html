AUDIO SYSTEM

CoolDiskRecorder

Загружай аудиофайлы и получай готовые команды для Minecraft-серверов. Прямые ссылки, автоматическая генерация команд, поддержка MP3/WAV/FLAC/OGG.

Доступные команды

DOWNLOAD

/cd download

Скачивает аудиофайл по прямой ссылке с указанием имени файла.

/cd download https://example.com/song.mp3 mysong.mp3
CREATE

/cd create local

Создаёт локальную аудиозапись для последующего воспроизведения.

/cd create local mysong.mp3 mysong.mp3
API

Upload API

Загрузка файлов через API с автоматической генерацией команд.

POST https://orrcs.vercel.app/api/upload

Как это работает

1. Загрузка файла

Вы загружаете аудиофайл через форму на сайте

2. Обработка

Файл загружается в облачное хранилище и получает прямую ссылку

3. Генерация команд

API автоматически создаёт команды для Minecraft

4. Использование

Вставляете команды в чат сервера и наслаждаетесь музыкой

Минус в этом...

Все файлы которым больше 10 часов каждый день удаляются для экономии ресурсов.
